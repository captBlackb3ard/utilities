# Network Information Gathering Scripts

This repository contains 3 scripts (Bash, Python, & PowerShell) that quickly retrieve network configuration information of the machine they are executed on.
Usage instructions are included within each script for easy reference.
Ideally, all scripts can execute with administrative privileges on Linux or Windows machines.
